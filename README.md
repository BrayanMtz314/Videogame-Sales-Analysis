# Video Game Sales Analysis

This dashboard presents a comprehensive analysis of the well-known 2016 Kaggle dataset, [Video Game Sales](https://www.kaggle.com/datasets/gregorut/videogamesales), created by GregorySmith.

This dataset records global sales for various video games and enables tasks such as data cleaning, exploratory analysis, regression, and classification, while also allowing you to answer numerous questions about the video game industry.

## Requirements

You only need the following:

- Python installed
- uv
- git

## Setup

1. Clone the repository using `git clone <URL>`
2. Navigate to the directory: `cd Videogame-Sales-Analysis/`
3. Download the necessary libraries with `uv sync`
4. Ensure you are in the Python environment; if not, use `source .venv/bin/activate`
5. Run the project with `uv run streamlit run Home.py`
